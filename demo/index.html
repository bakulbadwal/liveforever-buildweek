One person's health history, read as evidence.

LiveForever is a personal evidence lab. It joins wearable nights, daily habits, years of bloodwork and a genome into one record, tests one question at a time, and keeps the uncertainty on screen.

Bakul Badwal · Darden MBA '27 · built for OpenAI Build Week, July 2026

Maya Chen is fictional and every value on this page is synthetic. The private version of LiveForever runs on the author's own wearable data, a decade of coaching logs, bloodwork back to 2015 and his own 23andMe file; this public version replays the whole system on an invented person so anyone can inspect it.

One record, five layers

Nothing here is a single app's export. The value is the join: a night can be read against the habit logged that morning, a blood draw against the supplement running at the time, and a genotype against both.

Biological age across seven blood draws

PhenoAge turns nine routine blood markers plus calendar age into one number. It is an educational summary, not a clinical age. Select a draw to see every marker from that day against its reference range.

Do the practices work?

A year of 0/1 habits from the daily log, each compared with the next night's recovery on days it was done against days it was not. Several show nothing. That is the point of asking honestly.

Three dated changes, before and after

The 28 days after each change against the 28 before. This is the weakest evidence on the page: a window comparison cannot separate the change from everything else that moved in time. Because the record is synthetic, the generator's own truth is printed beside each result.

The genome, as context

Ten markers from a curated panel, each tied to something the record already tracks. A genotype can nominate a question or a lab to add. It never decides an answer. Turn the helix and select a lit base pair.

How it works

Code computes

Deterministic Python produces every number on this page: effect sizes, bootstrap intervals, lags, sample counts, missingness, correlations, PhenoAge, the quality grade and the retest schedule. The browser only draws what is in analysis.json and record.json.

The model explains

GPT-5.6, through the included Codex Skill, frames the question, reviews sources, explains the fixed result, names blind spots and adapts the plan to a person's constraints. It receives the numbers as an immutable contract and cannot change them, raise the grade or hide a warning.

Method and provenance

Privacy by construction

The public artifact is a fictional person end to end. No login, external health service, API key or live model call is needed to run it. The author's real databases, exports, lab PDFs, genome file and intervention history are excluded from this repository by design.
