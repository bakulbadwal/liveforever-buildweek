A personal health lab.

LiveForever puts wearable data, daily habits, years of blood work and a genome in one record. It tests one question at a time and keeps the uncertainty on screen.

Bakul Badwal · Darden MBA '27 · built for OpenAI Build Week, July 2026

Maya Chen is fictional, and every number here is synthetic. The private version runs on Bakul's own wearable data, ten years of coaching logs, blood work back to 2015 and his 23andMe genome. This one runs the same system on a made-up person so anyone can look inside.

One record, five layers

Everything shares a date. A night is read against that day's habits, a blood draw against the supplements she was taking, and a genotype against both.

Biological age (PhenoAge) across seven blood draws

PhenoAge is a published formula (Levine et al., 2018). It takes nine routine blood markers plus calendar age and returns an estimate of biological age. It's an educational number, not a clinical one. Select a draw to see that day's full panel.

Do the habits work?

Five daily habits, plus the caffeine cutoff, logged for a year. Each habit is compared with the next night's recovery on days done versus days skipped. Several show nothing, which is a real answer too.

The genome, as context

Ten markers, each checked against what the record tracks. A genotype can suggest a question or a lab to add. It never decides the answer. Drag to turn the helix and tap a lit rung.

How it works

Code computes

Plain Python computes every number on this page: effects, intervals, sample sizes, missing days, correlations, PhenoAge, the quality grade and the retest schedule. The browser only draws what's in analysis.json and record.json.

The model explains

GPT-5.6, through the included Codex skill, frames the question, explains the result, flags blind spots and fits the plan to a person's schedule. The numbers reach it as a locked file. It can't change them or hide a warning.

Method and provenance

Privacy

Everything public is a fictional person. It needs no login, health service, API key or live model call. Bakul's real data, lab PDFs and genome are never in this repo.
